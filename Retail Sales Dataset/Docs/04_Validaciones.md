## Validaciones

Para asegurar consistencia analítica se realizaron las siguientes validaciones:

- Comparación de ingresos totales entre SQL y Power BI.

- Verificación de crecimiento mensual (MoM).

- Confirmación de acumulado Pareto = 100%.

- Validación de Contribution % (suma total = 100%).

- Revisión de duplicados y consistencia en agregaciones.

Estas validaciones aseguran que los cálculos reflejan correctamente la estructura del dataset.
