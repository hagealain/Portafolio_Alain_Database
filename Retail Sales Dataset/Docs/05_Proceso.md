## Proceso

1. Extracción

    - Descarga del dataset público (Kaggle).

    - Carga en MySQL para análisis estructurado.

2. Transformación

    - Consultas SQL para agregaciones y métricas clave.

    - Implementación de funciones ventana para análisis Pareto.

    - Construcción de KPIs en Power BI mediante DAX.

    - Simulación de margen fijo del 40%.

3. Visualización

Se desarrollaron tres dashboards:

    - Performance Comercial

    - Concentración Demográfica

    - Simulación Financiera
